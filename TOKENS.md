# Tokens visuales observados

Extraídos de `:root` y reglas CSS de `src/client/Index.html`. Son valores existentes, no tokens aprobados como sistema universal.

| Token CSS / uso | Valor observado | Aplicación observada |
|---|---|---|
| `--nav` | `#173a5e` | Cabecera y pestaña seleccionada de catálogos |
| `--blue` | `#1f6fa8` | Acción primaria |
| `--line` | `#dbe3ed` | Bordes y divisores |
| `--muted` | `#66758a` | Texto secundario |
| `--danger` | `#b42318` | Errores/acciones de salida o cancelación |
| texto base | `#172033` | Color principal |
| fondo base | `#f4f7fb` | Fondo de página |
| fuente | `Inter, system-ui, -apple-system, "Segoe UI", sans-serif` | Tipografía general |

Colores de estado adicionales: disponible `#3d8b40`, ocupada `#c62828`, sucia `#f9a825`, limpieza `#1565c0`, mantenimiento `#424242`. Verificar contraste y estados renderizados en tarea específica antes de cambiar estilos.
